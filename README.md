# TEA — Aplicativo de esvanecimento de scripts

Artefato de pesquisa do **Relatório de Estágio Básico III**, de Edward Lúcio Vieira Borba,
sob orientação do professor Márcio Moreira.

O aplicativo implementa o procedimento de esvanecimento de scripts (*script-fading*) descrito por
Brown, Krantz, McClannahan e Poulson (2008), aplicado ao tema **tênis de mesa**, para treino de
reciprocidade de comunicação com jovens adultos autistas.

**Abrir:** https://edwardborba.github.io/TEA/

## Por que está publicado aqui

O modo de resposta por voz usa a Web Speech API do navegador, que exige origem `https` e permissão
de microfone. Abrir o arquivo direto do disco (`file://`) bloqueia o microfone. A publicação em
GitHub Pages dá ao arquivo uma URL `https` estável, que funciona em celular e tablet.

## Sobre o arquivo

`index.html` é o código **exatamente como foi gerado** pela ferramenta de IA, sem nenhuma
intervenção manual. Isso é condição do delineamento: o que se avalia é o artefato produzido pelo
comando, não uma versão corrigida dele. Um aplicativo remendado à mão deixaria de ser o artefato
que a pesquisa avalia.

- Data desta versão: 29 de setembro de 2026
- Comando de origem: **versão 8**, com doze itens e vinte e duas condições de aceitação
- Ferramenta geradora: Gemini
- Tema: tênis de mesa (o tema de verificação do estudo é o futebol brasileiro)
- Fase: desenvolvimento. A coleta de dados começa quando o comando estabilizar.

## Requisitos do modo por voz

Conexão com a internet, permissão de microfone e um navegador compatível (Chrome, Edge, Safari).
O Firefox não oferece reconhecimento de fala.
